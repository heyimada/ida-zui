# ida-zui UX / UI audit

Scope: the app as of commit `a4d7036`, judged against the goal "an easy-to-use, plug-and-play, modern replacement for the IDA Pro UI, with a proper menu bar". Evidence is either a screenshot in `artifacts/ui/` (the `a_*`, `l_*` and `w_*` files were captured for this audit on `find.exe` through `scripts/ui-capture.ps1`, with `-Work audit` so no user settings were touched; the rest are the existing captures) or a `file:line` in `crates/app/src`. Each finding says whether it was **verified visually (V)**, **inferred from code (C)** or **both (VC)**. Items already triaged in `docs/GAPS.md` are not repeated.

## Executive summary

**Verdict: a strong, coherent shell that a newcomer can use in a minute, but an IDA veteran will bounce within ten.** The chrome, menu bar, palette, loading screen, dialogs and themes are better than IDA's own. What is missing is the *editing surface* an experienced reverse engineer lives on: the right-click menu, text selection and copy, operand formatting (`H`, `O`, `R`, `T`, `*`), bookmarks, and more than one code view at a time. None of these are visual polish; they are the difference between "I can read a database here" and "I can do my job here".

Top 5 issues:

1. **No context menu anywhere** (H1). Right-click is how IDA users discover and run 80% of commands; here it does nothing.
2. **No selection or copy in the listing, graph, pseudocode or hex view** (H2). `Ctrl+C` copies nothing; only "Copy current address" exists.
3. **Operand formatting and the Edit menu's second half are absent** (H3). No hex/decimal/char/offset/struct-offset/enum/array, no "Edit function", no patching. The host protocol has no request for any of them.
4. **One code view per database** (H4). Linear / Graph / Hex / Pseudocode is a mode switch, plus one fixed split; nothing can be opened twice, torn off or put on a second monitor.
5. **`Ctrl+W` closes the database** (H5). In IDA it saves. The prompt's default button is *Save*, so `Ctrl+W`, `Enter` saves *and* closes, throwing the user out of the session they meant to checkpoint.

### Checked and not a problem

- Alt+letter, F10 and bare Alt reach the menu bar; arrow keys, Enter, Esc and letters work inside dropdowns (`menubar.rs`). Shortcut hints come from the live keymap, so rebinding updates the menus.
